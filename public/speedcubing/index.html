speedcubing times

Speedcubing is one of my main hobbies. I have created my own personal speedcubing timer that allows me to automatically upload my solves directly to a database after every single solve. This page reads that database and presents it such that the reader gets a broad overview of the events that I run along with my current averages / best times. More on the backend of this project can be found in my projects and my portfolio pages.

My main event that I practice is 3x3, however I have been learning and practicing 3x3 BLD offline and will be hoping to practice these on my database timer soon. I hope to branch out to eventually learning 4x4 and potentially 2x2, along with the respective BLDs aswell.
